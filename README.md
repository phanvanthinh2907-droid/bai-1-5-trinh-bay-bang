# Bài 1.5 - Trình bày bảng danh sách học phần

Bài tập chương 1 - HTML, sách *Bài tập Thiết kế Web* (NXB ĐHSP TP.HCM, 2023), học phần COMP1802.

Sinh viên thực hiện: Phan Văn Thịnh

Trong sách, trang này tên là `bang-hoc-phan.html`; ở đây đặt tên `index.html` để GitHub Pages tự mở.

## Kiến thức sử dụng
- Bảng: table, caption, thead, tbody, tr, th, td
- CSS ngoài: border-collapse, tô màu dòng chẵn/lẻ bằng nth-child
- Bảng cuộn ngang trên điện thoại

## Cách chạy
Mở thư mục bằng VS Code, chuột phải `index.html` → **Open with Live Server**.
